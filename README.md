#中药方剂查询工具
一个用python写的工具，可以查询常见的中药方剂的组成，功效以及主治，也是广中医准大一开学前的python练习作品
#功能
1.可以按方名搜索
2.可以按药材搜索
3.可以反复查询药剂，按3推出
# 使用方法
1. 步骤1：需要 Python 3
2. 步骤2：practice.py 和 fangji.json 放在同一目录
3. 步骤3：运行命令 python practice.py
# 数据
数据说明：内置 15 个常见方剂（桂枝汤、麻黄汤等），每个方剂包含方名、组成药材、功效、主治四个字段。
# 文件结构
-practice.py：主程序
-fangji.json：方剂数据
